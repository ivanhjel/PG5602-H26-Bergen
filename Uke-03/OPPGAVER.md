# Oppgaver – Uke 3

## Oppgave 5 – Test ulike API-er med APITester

Å bli kjent med nettverkskall og se hvordan ulike JSON-responser er bygget opp er viktig kunnskap som apputvikler.

Bruk **APITester**-appen vi laget i forelesningen og test URL-ene under.

- Kjør ett API-kall om gangen.
- Se på JSON-responsen du får tilbake.
- Bruk `print` for å undersøke verdier i koden.
- Sett minst ett breakpoint i koden som gjør nettverkskallet.
- Bruk debuggeren til å se hvilke verdier du har mens appen kjører.
- Sammenlign responsene. Legg merke til at JSON kan være bygget opp på veldig forskjellige måter.

### Bonus 💡

Finn et annet offentlig API som returnerer JSON og prøv URL-en i APITester.

Målet er ikke at du skal forstå alle feltene i responsen. Målet er å bli komfortabel med å gjøre nettverkskall, se på JSON og bruke verktøyene i Xcode for å undersøke hva som skjer.
